What changed for people using the application. Development detail lives in the private repository's changelog.

2.0.0 — first release of the rewrite (unreleased)

A ground-up rewrite of the earlier prototype.

  • Keyboard-safe passwords: every password uses only characters that keep their physical key position across QWERTY, QWERTZ and AZERTY layouts.
  • Password specifications: Active Directory / Entra ID, NIST passphrase, Console-safe, Wi-Fi passphrase, and PIN — each with an enforced minimum strength; word counts that could not reach it are not offered.
  • Name exclusion that follows the directory rule exactly (tokens of three or more letters), with the result re-checked.
  • Eight word lists — English, Catalan, German, Spanish, French, Italian, Portuguese and Chinese (pinyin) — with the interface in nine languages.
  • QR transfer to a nearby phone, on demand, self-hiding after 60 seconds; Share in the web app.
  • Web app installable to the home screen, working fully offline.
  • Desktop app for macOS (Linux to follow): native menus, About and Help, light/dark appearance, optional update check, clipboard auto-clear.
