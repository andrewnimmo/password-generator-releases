User guide

Password Generator makes passwords out of words — long enough to be strong, memorable enough to type — using only characters that sit on the same physical key on every common keyboard. This guide covers the desktop app and the web app together; they work the same way.

Making a password

  1. Choose a specification. Each one is a password policy: Active Directory / Entra ID (words, a capital and digits, at least 14 characters), Passphrase (NIST) (length first, plain lower-case words), Console-safe (letters and spaces only — safe even in a BIOS or recovery console), Wi-Fi passphrase, or PIN.
  2. Pick the number of words. Only counts that reach the specification's minimum strength are offered, so every choice on the list is a safe one.
  3. Pick a separator — a space between words, or none.
  4. Choose a word list. It follows the interface language by default; you can pick any of the eight languages independently.
  5. Optionally enter your name or username. Directory policies often reject passwords containing part of your name; when you enter it, words containing any part of it (three letters or more) are excluded, and the final password is checked again. It is used only for this and never stored.
  6. Press Generate.

The bar above the button shows the strength of what you will get — in bits of entropy, alongside the specification's minimum. Each extra word roughly doubles the possibilities eleven times over.

Reading the result

The password appears in the card. On screen, each space is marked with a faint dot so you can tell, even where the text wraps across lines, whether a separator sits at the break. The dot is display only — Copy, the QR code and Share all carry the real password with plain spaces.

  • Copy puts the password on the clipboard. On the desktop app, the clipboard is cleared 60 seconds later if it still holds the password (switch this off in About if you prefer).
  • Show QR displays the password as a QR code for a phone camera — nothing is sent anywhere; the only channel is light. The code hides itself after 60 seconds. Anyone who can see the code can read the password, so mind who is behind you.
  • Share (web app, where the browser offers it) opens the device's share sheet.

Why "keyboard-safe"?

Type a password on a QWERTY keyboard while the machine believes it is AZERTY and mama comes out as ,q,q. Only characters that occupy the same physical key in every covered layout are immune. Deriving that set from real layout data leaves twenty letters, the space bar, and — with one caveat — the digits: on a French (AZERTY) keyboard, digits need Shift. Every password this application makes uses only those characters, so it types correctly even on a console set to the wrong layout.

Languages and appearance

Open About (the i button, or the Help menu) to choose the interface language — which also selects the matching word list — and the appearance: match the system, light, or dark. The desktop app can check for updates when you ask it to; nothing is checked unless you enable it.

The web app on a phone

Open the web app in your browser and add it to your home screen: on Android and desktop browsers, use the Install prompt or menu item; on iPhone and iPad, tap Share → Add to Home Screen. Once installed it works offline, and nothing you generate ever leaves the device.

Privacy

The application stores nothing but your preferences, sends nothing anywhere, and uses a cryptographically secure random source for every password. The name you enter for exclusion is used in memory only.
