User guide

Password Generator makes passwords out of words — long enough to be strong, memorable enough to type — using only characters that sit on the same physical key on every common keyboard. This guide covers the desktop app and the web app together; they work the same way.

Making a password

  1. Choose a specification. Each one is a password policy: Active Directory / Entra ID (words with capitals and digits, at least 14 characters), Passphrase (NIST) (length first, plain words), Console-safe (letters and spaces only — safe even in a BIOS or recovery console), Wi-Fi passphrase, or PIN.
  2. Pick the number of words. Only counts that reach the specification's minimum strength are offered, so every choice on the list is a safe one.
  3. Pick a separator — a full stop between words (the default), none, a space, or a number: one digit between each pair of words, which replaces the two digits at the end. The full stop sits on a different key on French, Belgian, Turkish and Russian keyboards; pick none or space if that matters to you. Console-safe offers none and space only.
  4. Choose the capitals — every word (the default), which keeps the word boundaries visible whatever the separator, or the first word only.
  5. Choose a word list. It follows the interface language by default; you can pick any of the eight languages independently.
  6. Enter your full name (recommended), as your work account shows it, with middle names; on the desktop, Add account name appends your account name. Directory policies reject passwords containing part of your full name; when you enter it, words containing any part of it (three letters or more) are excluded, and the final password is checked again. A sign-in name typed as an email address is split into its parts. Leave the field blank and the password is still made, with a warning that it was not checked against your name. Never stored.
  7. Press Generate.

The bar above the button shows the strength of what you will get — in bits of entropy, alongside the specification's minimum. Each extra word roughly doubles the possibilities eleven times over.

Reading the result

The password appears in the card exactly as you will type it, and lines break only between words. With the space separator, each space is shown as a small key marked "space" — the key is a picture, never part of the password, and selecting the text copies the real password. Under the password a caption says what it is made of ("4 words, a full stop between each, then 35"), then the strength, then "Tap to copy" ("Click to copy" on the desktop). Tapping or clicking the card copies the password; so does the Copy button. "Copied" appears only once the clipboard has taken it; if it could not, the card says so and you can select the text instead. If you generated without your name under a specification that excludes names, a warning under the card says the password was not checked against it.

  • Copy puts the password on the clipboard. On the desktop app, the clipboard is cleared 60 seconds later if it still holds the password (switch this off in About if you prefer).
  • Show QR displays the password as a QR code for a phone camera — nothing is sent anywhere; the only channel is light. The code hides itself after 60 seconds. Anyone who can see the code can read the password, so mind who is behind you.
  • Share (web app, where the browser offers it) opens the device's share sheet.

Why "keyboard-safe"?

Type a password on a QWERTY keyboard while the machine believes it is AZERTY and mama comes out as ,q,q. Only characters that occupy the same physical key in every covered layout are immune. Deriving that set from real layout data leaves twenty letters, the space bar, and — with one caveat — the digits: on a French (AZERTY) keyboard, digits need Shift. Every password this application makes uses only those characters, so it types correctly even on a console set to the wrong layout — with one deliberate exception: the full stop used as the default separator sits on the same key on most layouts but not on French, Belgian, Turkish or Russian keyboards. Choose none or space if you need the strict guarantee; Console-safe never offers the full stop.

Languages and appearance

Open About (the i button, or the Help menu) to choose the interface language — which also selects the matching word list — and the appearance: match the system, light, or dark. The desktop app can check for updates when you ask it to; nothing is checked unless you enable it.

About also holds the reveal effect: a short animation, off by default, that shows the words settling into place after Generate — Reels (each word spins through other words and stops, left to right), Decode (every character flickers and locks in), Typewriter, or Surprise me for one of the three each time — at a speed of your choice. It is purely visual: the password is made first, the animation never changes it, a tap or click on the card ends it at once and copies, and the web app shows the result immediately if your device asks for reduced motion.

The web app on a phone

Open the web app in your browser and add it to your home screen: on Android and desktop browsers, use the Install prompt or menu item; on iPhone and iPad, tap Share → Add to Home Screen. Once installed it works offline, and nothing you generate ever leaves the device.

Privacy

The application stores nothing but your preferences, sends nothing anywhere, and uses a cryptographically secure random source for every password. The name you enter for exclusion is used in memory only.
