# Changelog

All notable changes to this project. Versioning starts at 2.0.0 on first
release (ratified 2026-08-31); until then everything accumulates under
Unreleased.

## [Unreleased]

### Added (M6 local lane — macOS packaging, 2026-09-01)

- `bb package-mac` builds "Password Generator-2.0.0.dmg" locally with
  jpackage (csv-cleaver's script, ported with its lessons: the full
  module list including jdk.localedata, an app-image start check before
  the DMG exists, hardened-runtime entitlements ready for signing via
  MACOS_SIGNING_IDENTITY). 62 MB — half the legacy prototype's size.
- The desktop uberjar (`clojure -T:build uber-desktop`) AOT-compiles only
  a new thin launcher (pwgen.desktop.main — also answers --version), so
  the JavaFX toolkit never boots inside the build JVM; build-info.edn now
  stamps every jar with the git commit, and About shows it.
- The installer carries LICENSE, NOTICE, THIRD-PARTY.md and WORDLISTS.md
  inside the app bundle; the icns derives from the same `bb icons` script
  as every other icon.
- Second vulnerability-scanning lane: `bb sec-nvd` runs clj-watson's
  dependency-check strategy against the NVD, keyed by the gitignored
  .nvd-api-key file Andrew provided.

### Added (app icon, 2026-09-01)

- The application icon, to Andrew's design: a masked password — four
  black discs in a white field — on a regal Tyrian-purple gradient.
  Generated by `bb icons` from one script (an asterisk variant renders
  alongside; the shipped glyph is a one-word switch), wired into the PWA
  manifest and splash, the favicon, and both About screens. macOS icns /
  Windows ico derivation from the same art lands with M6 packaging.

### Added (M5 — QR transfer, 2026-08-31)

- Both apps can show the generated password as a QR code for a nearby
  phone's camera — air-gapped by design: the password never transits any
  network. On demand only (a "Show QR" button beside Copy), with a
  shoulder-surfing caution, self-hiding after 60 seconds, the rendered
  code cleared with the overlay. Desktop encodes with ZXing; web with the
  dependency-free qrcode-generator (MIT), drawn entirely in-page.
- The web app additionally offers the native share sheet (AirDrop / Quick
  Share) where the browser provides one.
- Proof both ways: the JVM suite encodes with ZXing and DECODES with
  ZXing's reader (round trip, tonalcode discipline); the web build's
  rendered image was decoded back to the exact password by Chromium's
  BarcodeDetector during live verification.

### Fixed (build correctness, 2026-08-31)

- inline-edn now reads through shadow.resource/slurp-resource when
  compiling ClojureScript, registering embedded EDN files with the build —
  previously an edited resource (i18n.edn) could ship STALE inside a web
  release because shadow's cache never saw it change. Found live when the
  QR strings appeared as raw keys.

### Added (M4 — web PWA twin, 2026-08-31)

- The web application (`bb web` → `public/`): the desktop mirrored in the
  browser from the same cljc core and the same shared view-model
  (`pwgen.ui`, extracted from the desktop shell so the two cannot drift) —
  identical controls, trimmed word-count picker, live entropy meter,
  password card, About/Help overlays with the dictionary entry, nine
  languages with the same explicit-choice/divergence persistence rules
  (browser storage), light/dark/match-the-system theming.
- Installable offline PWA: manifest + service worker precaching the app
  and all 16 word lists (which ship as static EDN assets rather than in
  the JS bundle — 640 KB of code stays 640 KB); every request is
  same-origin, nothing external, nothing sent anywhere.
- Web divergences, by browser reality: no clipboard auto-clear (a page
  cannot politely verify clipboard ownership), no update check (a page is
  always current), no bundled-runtime notice, no system-username button.
- Placeholder app icon (abstract passphrase bars) for the PWA install and
  the About overlay.

### Changed (M3 visual QA round 5 — About ported faithfully, 2026-08-31)

- The About overlay now mirrors csv-cleaver element for element: icon
  placeholder (shows automatically once packaging adds icon.png), "About
  {app}" title with tagline, a dictionary-style entry for "password" (IPA,
  part of speech, two senses, and the note: impossible to guess, easy to
  type — even on the wrong keyboard), the bundled-Java-runtime notice,
  and "Made with 🤖 in Barcelona" — all in nine languages, using
  csv-cleaver's exact wording for every shared string ("Licensed under…",
  "Match the system", "Check automatically when the application starts",
  update statuses).
- A separator now divides Appearance from the clipboard option, which had
  read as part of the theme section.
- Kept as a deliberate improvement over csv-cleaver: the language dropdown
  marks the current language with a grey background rather than a tick.

### Changed (M3 visual QA round 4, 2026-08-31, by ruling)

- Word counts that cannot meet the spec's entropy floor are simply not
  offered — the picker lists only reachable counts (the intermediate
  greyed-cell attempt rendered with no visible difference, which was worse
  than either; an entry that can never be chosen is not shown at all).
  When name filtering shrinks the list beneath the current choice, the
  picker climbs to the smallest valid count; the raised-warning message is
  gone entirely.
- Help gains an entropy topic: what entropy is, and why the minimum
  matters (all nine languages).

### Fixed (M3 visual QA round 3, 2026-08-31)

- About's auto-clear option says "60 seconds" in every language (was "60 s").
- The entropy preview now visibly reacts when the floor raises the word
  count: the single line under the bar becomes the raised message with the
  resulting entropy inline (was an unchanged meter reading plus a separate
  note).

### Fixed (M3 visual QA round 2, 2026-08-31)

- The interface language now always follows the system locale at first
  launch; only a language explicitly picked in About is persisted (a
  --locale override applies to that run only). A verification smoke run
  had also written :de into the real settings file — --smoke runs are now
  transient and never write settings.
- Pressing Copy no longer nudges the password: the button's size is
  invariant (colour-only feedback; the "Copied ✓" confirmation appears in
  the card's meta line instead of changing the button text).

### Changed (M3 revision — csv-cleaver patterns, 2026-08-31, by ruling)

- About and Help are now in-window overlays (dim backdrop + card); About
  hosts the options that affect the main window: language (which also
  selects the matching word list — the main-window picker may diverge, and
  only a genuine divergence is pinned across sessions), appearance
  (AtlantaFX System/Light/Dark), clipboard auto-clear, and the update
  check. Round ?/i header buttons open the same overlays.
- Menus slimmed to csv-cleaver's reasoning: no File menu on macOS (Glass
  provides Quit natively; About is installed into the native application
  menu via JNA); File(Quit)/Help(Help, About) elsewhere; Generate is the
  footer's accented default button instead of a menu chord.
- Generated password presented as a tinted card — large monospace, centred,
  Copy directly beside it, entropy underneath; the "Press Generate"
  placeholder is gone (nothing shows before the first generate).
- Settings moved from java.util.prefs to an EDN file in the platform's own
  config directory, saved at quit and from a JVM shutdown hook; window
  geometry remembered (sanity-checked on restore).
- Update check ported from csv-cleaver: manual-first from About, opt-in
  startup check surfacing only as a quiet footer link, --no-update-check
  removes the feature; endpoint derived from branding.edn's :homepage.
- Identity centralised in resources/branding.edn (name, version, copyright,
  contact, homepage) with a build-info commit stamp planned in packaging.

### Added (M3 — desktop app, 2026-08-31)

- cljfx desktop application (`bb app`): native menu bar with working
  ⌘G/⌘Q/⌘⇧C, orderly shutdown from menu, ⌘Q and window close alike
  (implicit exit re-enabled — the legacy zombie-JVM quit bug is
  structurally gone), spec/word-count/separator/word-list pickers, live
  entropy meter with floor and auto-raise preview, AD name field with
  one-click system username, About and Help windows, inline error
  messages, OS light/dark theme following with live switching, clipboard
  copy with 60 s auto-clear (only if the clipboard still holds our value),
  preferences persisted per change.
- Full UI internationalisation: nine locales in resources/i18n.edn with an
  enforced complete-key-set test; locale detected once at startup,
  overridable in-app and via --locale.
- Runtime word-list loader with :en fallback for locales without lists
  (visible note in the UI); JavaFX pinned to 26.0.2 with only
  controls/graphics/base shipped; version single-sourced from
  resources/version.edn.

### Changed (SPEC §7 amendment, 2026-08-31)

- Word lists keep ALL usable words (Andrew's ruling on the measured
  truncation-cliff cost); bits/word is now fractional. Invariant tiers grew
  from 1024–2048 to 1832–3213 words; standard tiers to 7772–8192.

### Added (M2 — word-list pipeline, 2026-08-31)

- `bb wordlists`: reproducible word-list build pipeline — sha256-pinned
  upstream sources (`resources/wordlist-sources.edn`), Unicode
  normalisation, tier filtering, deterministic power-of-two truncation,
  per-file license/modification headers, generated manifest and
  docs/WORDLISTS.md attribution; `--check` verifies committed lists
  reproduce from the pins.
- 16 shipped lists: en/ca/de/es/fr/it/pt/zh × standard/invariant tiers
  (1024–8192 words), all license-cleared (CC0/CC-BY/CC-BY-SA; zh GPL-3.0
  with full license text shipped alongside). Japanese pending source
  verification.
- CLI reads generated list files directly
  (`clojure -M:cli -l resources/wordlists/en-invariant.edn`).

### Added (M1 — core engine, 2026-08-31)

- Pure `.cljc` generation engine: injected CSPRNG (SecureRandom /
  crypto.getRandomValues with rejection sampling), diceware-style draws
  with replacement, closed-form entropy accounting with per-spec floors and
  automatic word-count raising.
- Keyboard-invariance model: charset tiers derived at compile time from
  physical layout data (`resources/layouts.edn`).
- Policy-as-data: malli-validated password specifications
  (`resources/specs.edn`) — ad-entra, nist-passphrase, console-safe, wifi,
  pin — plus safe EDN parsing for user-supplied specs.
- AD-style name-token exclusion (3+ character tokens only), with
  assembled-password re-checking for boundary-straddling tokens.
- Locale discipline namespace (`pwgen.i18n`, Locale/ROOT everywhere) with
  clj-kondo bans on insecure RNG and locale-sensitive case/format calls.
- Headless CLI (`clojure -M:cli`, uberjar via tools.build).
- Test suite: 32 tests / 166 assertions running identically on the JVM and
  Node, including property-based tests, a tr_TR locale lane, and documented
  mutation checks (docs/VERIFICATION.md).
